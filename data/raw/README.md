# Synthetic source corpus (DEMO DATA)

Every company, product, rate, rule, phone number, and person in this folder is **fictional** and was
created for the assessment. Nothing here is real financial or insurance advice.

| Market | Fictional brand | Use case |
|---|---|---|
| India (Q1/Q2) | Kosha Capital | Unsecured business-loan lead qualification |
| Philippines (Q3) | Lumina Life Philippines + Bangko Kapwa | Bancassurance life-insurance lead qualification |
| Indonesia (Q3) | Sinar Multifinance | Motorcycle-financing installment reminder |

The corpus intentionally contains production-style defects so the ingestion pipeline can demonstrate
cleaning:

- navigation, cookie banners, headers, and footers repeated on every web page
- `web/business-loan-faq-2025.html`: an older near-duplicate of the current FAQ
- `docs/credit_policy_v1.pdf` vs `docs/credit_policy_v2.pdf`: superseded and current policy versions
- `docs/fees_and_charges.csv`: a typo (`processing fee 25%`) that must be flagged as a source error
- `docs/brochure_corrupted.pdf`: an unreadable file that must be logged as an extraction failure
- `docs/call_notes_export.txt`: fake customer PII (names, phone numbers, PAN, Aadhaar, email)
- inconsistent terminology (EMI / monthly instalment, turnover / revenue, CIBIL / credit score)

PDFs are regenerated by `python backend/scripts/make_sample_pdfs.py`.
